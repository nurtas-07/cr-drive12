# CR Drive · Cinematic

Новая версия на основе `cr-drive-site-main.zip`. Главная страница переведена на React + TypeScript для интеграции присланных компонентов. Рабочий кабинет диспетчера сохранён отдельной страницей из архива.

## Разработка

Требуется Node.js 20.19+ или 22.12+ с npm. Выполняйте команды по одной строке в CMD из этой папки:

```cmd
npm ci
npm run dev
```

Откройте адрес, который напечатает Vite. Сборка:

```cmd
npm run check
npm run build
```

Результат — `dist`. Эта папка целиком подходит для статического хостинга. `base: './'` обеспечивает пути внутри репозитория GitHub Pages. Node.js нужен для разработки и локального сервера; на опубликованном статическом сайте сервер Node.js не нужен.

## Структура shadcn, Tailwind и TypeScript

Всё уже установлено и настроено. Повторять `shadcn init` не нужно.

- `src/components/ui/` — общие UI-компоненты, стандартный путь `@/components/ui`.
- `src/components/ui/shimmer-text.tsx` — присланный ShimmerText; улучшена поддержка reduced motion и параметра spread.
- `src/components/ui/pricing.tsx` — Pricing: Motion, NumberFlow, Radix Switch, конфетти, реальные суммы в тенге.
- `src/components/ui/demo.tsx` — отдельные примеры использования компонентов.
- `src/components/ui/button.tsx`, `label.tsx`, `switch.tsx` — shadcn-совместимые примитивы.
- `src/lib/utils.ts` — `cn` через clsx и tailwind-merge.
- `src/hooks/use-media-query.ts` — подписка на изменение размера экрана.
- `src/styles.css` — Tailwind CSS 4, дизайн-токены, стили и адаптивность.
- `components.json` — конфигурация shadcn CLI; alias `@/` указывает на `src/` в TypeScript и Vite.

Папка `src/components/ui` выделена для повторно используемых компонентов и совместимости с импортами из присланных промптов. Проект не использует Next.js, поэтому ссылки — стандартные `<a>` вместо `next/link`. Платёжного провайдера или платного оформления заказов нет: кнопки открывают существующий Telegram команды.

Для добавления новых компонентов можно применять shadcn CLI (`npx shadcn@latest add имя-компонента`). Не перезаписывайте существующие button/label/switch без сравнения изменений: они оформлены под CR Drive.

## Что редактировать

- `src/content.ts`: тексты RU/KZ/EN, контакты, FAQ, новости.
- `src/components/ui/pricing.tsx`: `makePlans` и ставки калькулятора. 45 000 ₸ — устройство, 3 000 ₸ — месяц, 36 000 ₸ — 12 месяцев без выдуманной скидки. Это ориентиры из презентации, не публичная оферта.
- `src/components/Intro.tsx`: последовательность вступления: монтаж 3,6 с → фраза 1,5 с → бренд 2,6 с. Автоматически один раз на вкладку; повтор — по кнопке. Skip и Escape закрывают вступление.
- `src/components/Dashboard.tsx`: демонстрация обычного рейса, тревоги, потери связи и снятия часов. Водитель может отправить ответ внутри демо. Сетевые сообщения из демо не отправляются.
- `public/dispatcher.*`, `public/runtime-config.js`: существующий рабочий кабинет с исходной авторизацией Supabase. Пользовательские учётные данные не добавлялись.

В режиме уменьшения анимации автоматическое вступление показывает короткий статичный логотип. Явное нажатие «Смотреть вступление» запускает монтаж. Звука, мерцания и вспышек нет.

В рабочем кабинете обновлены оформление и относительные пути service worker/manifest для работы внутри `/cr-drive/`. Убрано ложное сообщение о завершении сессии при первом открытии без входа. Кэш ограничен файлами кабинета; API и данные пользователей не кэшируются. Пароли, ролевые политики и схема сервера не изменялись. Работу с реальными показаниями следует проверять своей учётной записью.
